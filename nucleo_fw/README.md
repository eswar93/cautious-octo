# nucleo_fw — base station (NUCLEO-F767ZI)

`app/` and `../core/` are the only hand-written sources. Everything else (HAL, lwIP, FreeRTOS,
startup, linker script) is generated by STM32CubeMX — that is deliberate, so regenerating never
clobbers your code.

## One-time setup (Windows 11)
1. Install: STM32CubeMX, VS Code + **STM32 VS Code Extension** (installs the Arm toolchain, CMake,
   OpenOCD, CubeProgrammer), ST-LINK drivers come with CubeMX.
2. CubeMX: *New project -> Board selector -> NUCLEO-F767ZI*, accept default peripherals.
   - Connectivity -> **ETH**: RMII mode (the board's pins are preconfigured by the board preset).
   - Middleware -> **FREERTOS** (CMSIS_V2) and **LWIP**: enable DHCP, keep default socket API on.
   - Heap: raise FreeRTOS `TOTAL_HEAP_SIZE` to >= 32 KB.
   - Project Manager: *Toolchain/IDE = CMake* (STM32CubeIDE-free workflow).
   - Save the project **into this folder** (`nucleo_fw/`).
3. Add to the generated `CMakeLists.txt`:
   ```cmake
   target_include_directories(${CMAKE_PROJECT_NAME} PRIVATE
       ../core app ../third_party/mavlink/c_library_v2/common ../third_party/mavlink/c_library_v2)
   target_sources(${CMAKE_PROJECT_NAME} PRIVATE
       app/app.c app/udp_task.c ../core/tw.c ../core/link_monitor.c ../core/predictor.c)
   target_link_libraries(${CMAKE_PROJECT_NAME} m)
   ```
4. In `Core/Src/freertos.c` (USER CODE sections) create the task after `MX_LWIP_Init()`:
   `xTaskCreate(udp_task, "udp", 1024, NULL, tskIDLE_PRIORITY + 3, NULL);` and declare
   `void udp_task(void *);`. Give the udp task >= 4 KB of stack (value is in words in FreeRTOS raw API).
5. `tools/fetch_mavlink.ps1` once, then build/flash from the VS Code extension.

## Debugging
- Nucleo gets its IP by DHCP: read it from your router's client list, then point the ESP32 at it
  (`idf.py menuconfig` -> Remote node -> Base station IP).
- Run Wireshark on the PC with filter `udp.port == 14550` (MAVLink dissector is built in).
- ST-LINK virtual COM port (USART3, 115200) is handy for `printf` logging.
